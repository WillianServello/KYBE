# 🎵 KYBE

KYBE é um projeto pessoal desenvolvido com o objetivo de praticar conceitos de desenvolvimento back-end, arquitetura de software e boas práticas de programação.

A proposta do sistema é criar uma plataforma voltada para o universo musical, reunindo conteúdos, produtos e informações em um único ambiente.

> ⚠️ Projeto em desenvolvimento e utilizado principalmente para estudos, experimentação de tecnologias e aprimoramento técnico.

---

# 🚀 Objetivos

Este projeto foi criado para aprofundar conhecimentos em:

- Arquitetura em Camadas

# 🏗️ Arquitetura

O projeto segue o padrão de Arquitetura em Camadas para promover organização, manutenção e escalabilidade.

```text
Presentation
│
├── Controllers
├── Views
└── ViewModels

Application
│
├── Services
├── DTOs
└── Interfaces

Domain
│
├── Entities
├── Enums
├── Validations
└── Contracts

Infrastructure
│
├── Repository
├── Context
├── Mappings
└── Migrations
```
